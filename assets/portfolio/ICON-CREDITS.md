# Portfolio assets

The hero and project components have desktop/mobile and dark/light variants. Project text can be edited directly inside the SVG files; preserve the corresponding image alt text in the profile README. Technology tiles are fixed-size and wrap naturally. No external fonts, scripts, animation, or runtime image services are required.

## Icon sources

The technology tiles embed Skill Icons (MIT) and pandas/NumPy from Simple Icons (CC0). PostGIS, Whisper and pyannote.audio use original symbolic glyphs, not official brand marks.

- Skill Icons: https://github.com/tandpfun/skill-icons
- Simple Icons: https://github.com/simple-icons/simple-icons
